# アニメのスクリーンショットから原画風画像へ · Reverse Anime Genga

アニメの完成映像のスクリーンショットから、制作情報を含む日本式のアニメ原画風画像を逆算して作成する AI Agent Skill です。

本スキルが生成するのは原画風の画像であり、実際のアニメ制作に使われる原画とは依然として大きな隔たりがあります。本物の原画における形の描き方、セル分け、色トレス線、注記は、具体的な動きの設計や後工程への指示のために存在します。完成映像の1フレームだけでは、これらの制作情報を完全には復元できません。生成結果のフレーム外の描き足し、素材分け、注記には推測が含まれ、誤りも生じ得ます。そのため、視覚的なシミュレーションなどを楽しむ用途に適しており、元の制作資料を正確に復元したものとして扱ったり、後工程で使用できる原画の代わりにしたりすることはできません。

## できること

重視するのは、**原画にどの情報を残し、何を省略すべきか**という判断です。元の構図とキャラクターの造形を保ちながら、セル分け、背景の簡略化、フレーム外の描き足し、影・ハイライトの色トレス線、作業上意味のある手書き注記を検討します。

- アニメのスクリーンショットを、白地に撮影フレームを示した原画風の図に変換します。
- セルの分けすぎ、背景の描き込みすぎ、フレーム外の情報不足、色トレス線の欠落などを修正します。
- 推測に基づいて原画番号、「止め」「口パク」「クミ」などの注記を加え、その指示に意味があるかを確認します。
- 完成映像から確認できる情報と、制作上の推測を区別します。

本スキルは AI エージェント向けの指示と参考資料をまとめたもので、単独で動作する画像変換プログラム、モデルの重み、学習用データセットではありません。実際に画像を作成するには、利用環境に画像生成・編集機能が必要です。

## 基本方針

| 項目 | 処理方針 |
| --- | --- |
| 構図 | 撮影フレーム内の人物の大きさ、位置、表情、手の形、重なり方を保つ |
| 省略 | 背景は位置・接触・重なりを示すために必要なアタリにとどめ、装飾や質感の細部を省く |
| セル分け | 独立したタイミング、動き、流用、撮影処理の必要性に応じて判断し、機械的に分割しない |
| フレーム外の描き足し | 頭頂部、肘、袖口、しっぽの先など、少しだけ切れている必要な部分を補う。必要なら用紙を広げ、撮影フレームは変えない |
| 色トレス線 | 赤や青などの境界線で実際の影・ハイライトや色分けを示し、無作為に色線を加えない |
| 注記 | 対象の近くに書き、素材の識別、クミの関係、必要な制作指示を伝える |
| 筆跡 | 各画を一度で素早く書き、大きさや字間に自然な手書きらしい変化を持たせ、均一で硬い見た目を避ける |
| 線の重なり | 注記は既存の線に直接重ね、白縁や消去帯で下の線を途切れさせない |
| 画面の体裁 | 平坦な白地とし、紙の質感、タップ穴、字幕、配信プラットフォームの透かしは表示しない |

各素材グループの丸囲み番号は、A①、B③など、妥当な範囲で仮に設定できます。スクリーンショットから復元した実際の制作番号ではなく、グループ間の登場順を表すものでもありません。

## 著作権に関する注意

商業アニメのスクリーンショットを本スキルで処理する場合、入力素材と生成結果に残る保護対象の表現について、第三者の著作権が関係する可能性があります。完成映像を線画や原画風の画像に変換しても、元の作品の著作権上の制約が自動的になくなるわけではありません。出典の明記、非営利目的、「学習目的に限る」といった表記だけで、当然に免責されるわけでもありません。素材を第三者の AI サービスへアップロードする前や、生成結果を公開・配布・販売その他の方法で利用する前に、必要な許諾を得ているか、または適用される法律上の著作権の例外に該当するかを確認してください。本プロジェクトは、第三者の作品に関する利用権を付与しません。公開する際は作品名や出典を適切に示すとともに、AI が完成映像から逆算して生成した参考画像であることを明記し、公式の原画や実際の制作資料と誤認されないようにしてください。

## 使い方

### Agent Skills に対応した環境

1. 本リポジトリをダウンロードまたはクローンします。
2. `reverse-anime-genga/` フォルダーを利用するエージェントのスキルインストール機能に渡すか、その環境の手順に従ってスキル用ディレクトリに配置します。`SKILL.md`、`references/`、`agents/`、`assets/` はすべて保持してください。
3. アニメのスクリーンショットをアップロードし、`reverse-anime-genga` を呼び出します。呼び出し方やインストール先は、利用環境の仕様に従ってください。

依頼例：

> reverse-anime-genga を使って、このスクリーンショットを原画風の画像にしてください。元の構図を保ち、適切にセル分けを判断して、撮影フレームで少しだけ切れている部分を描き足してください。

部分修正の例：

> この画像の構図と色トレス線を保ち、注記だけを修正してください。各画は一度だけ書き、字間、大きさ、傾きをもっと自然にばらつかせてください。注記は既存の線に重ね、周囲を白く消さないでください。

> 右腕は肘の部分だけが切れています。用紙を右側に広げ、フレーム内の肩と手の位置を変えずに、曲がった肘を最後まで描いてください。

### 自動インストールに対応していない環境

エージェントに [SKILL.md](reverse-anime-genga/SKILL.md) を読ませ、そこから参照される資料も読めるようにしたうえで、スクリーンショットと作業内容を渡してください。テキストのみを扱う環境では、逆算の方針を立てたり注記の整合性を確認したりできますが、それだけで画像を生成したことにはなりません。

## 参考資料と設計の背景

本スキルは、スクリーンショットからの逆算を繰り返し試し、具体的な問題へのフィードバックと公開されている作画資料を整理して作成しました。参考資料には、P.A.WORKS の作画指導、REVOROOT のデジタル作画マニュアル、日本アニメーションおよび CELSYS のチュートリアル、WEBアニメスタイルの撮影講座、原画サンプルの解説、アニメーター育成資料などがあります。

各資料へのリンクと参照目的は、[制作知識と出典](reverse-anime-genga/references/production-knowledge.md)を参照してください。本リポジトリには要約と出典を収録し、第三者のチュートリアル本文やサンプル画像は同梱していません。

会社やカットによって、素材の分け方、線の色、制作手順は異なります。本スキルでは、白地での表示、一度書きの手書き注記、必要な部分だけのフレーム外の描き足しなどを標準の出力方針としていますが、これらをアニメ制作全体に共通する規則として扱ってはいません。

## 制約

- 完成映像の1フレームだけでは、実際の原画、セル分け、タイミング、カメラワーク、フレーム外の形状を一意に特定できません。出力は制作上の整合性を考慮した推測図です。
- 画像モデルは、指、輪郭、日本語、番号などを誤って生成する場合があります。結果を確認し、必要に応じて部分修正してください。
- 画像に A/B の素材グループを示しても、実際に編集可能な独立レイヤーが含まれているとは限りません。
- このバージョンでは、テキストによる場面設定を用いた方針の確認を行っています。すべての画像モデルやカットでの結果を保証するものではありません。
