# 动画截图逆向原画 · Reverse Anime Genga

将动画成片截图逆向为具有制作信息的日式动画原画稿的 AI Agent Skill。

本 skill 生成的是具有原画风格的图片，与真正用于动画制作的原画仍有明显差距。真实原画中的造型、分层、色线和标记服务于具体的动作设计及工序交接，而单张成片无法完整还原这些制作信息。生成结果中的框外补画、素材划分和注释包含推测，也可能存在错误，因此更适合作为视觉模拟等趣味性使用，不能视为原始制作资料的准确复原，也不能直接替代可用于后续制作的原画。

## 适合做什么

它关注的是：**原画里应当留下什么信息，以及哪些内容应当省略。** 在保留镜头构图和角色造型的基础上，判断素材分层、背景简化、框外补画、阴影高光色线及功能性手写标记。

- 将动画截图转换为白底、带取景框的原画示意稿。
- 修订生成稿中的过度分层、背景过细、框外信息缺失、缺失色线等问题。
- 依据推断加入原画号、止め、口パク、クミ等术语，并检查是否有意义。
- 将成片中可见的信息与合理的制作推断区分开。

这是一套供 AI Agent 执行的指令与参考资料，不是独立运行的图像转换程序，也不是模型权重或训练数据集。实际绘图需要所用环境提供图像生成或编辑能力。

## 核心原则

| 方面 | 处理方式 |
| --- | --- |
| 构图 | 保持取景框内的人物尺度、位置、表情、手姿和遮挡关系 |
| 省略 | 背景只留定位、接触与遮挡所需框架，省去装饰和材质细节 |
| 分层 | 按独立时序、运动、复用及摄影处理需要判断，不机械拆开 |
| 框外补画 | 补全邻近被裁的头顶、肘部、袖口、尾尖等必要内容；如有需要则扩大纸面，不改变取景框 |
| 色线 | 用红蓝等色界线表达实际光影和色分信息，不随机添加彩色线条 |
| 标记 | 写在相关对象附近，说明素材身份、组合关系及必要的制作指示 |
| 笔迹 | 单笔快写、大小和间距自然仿照手写风格，不均匀死板 |
| 叠线 | 标注直接叠在原线条上，不用白边或擦除带切断底下的线 |
| 版面 | 纯白平面，不展示纸纹、定位孔、字幕和平台水印 |

各素材组的圈号可合理虚构，例如 A①、B③；它们不是从截图恢复出的真实生产编号，也不表示跨组的出场先后。

## 使用方法

### 支持 Agent Skills 的环境

1. 下载或克隆本仓库。
2. 将其中的 `reverse-anime-genga/` 文件夹交给所用 Agent 的 skill 安装入口，或按该环境的安装方式放入技能目录。应完整保留 `SKILL.md`、`references/`、`agents/` 和 `assets/`。
3. 上传动画截图，调用 `reverse-anime-genga`。名称的调用语法和安装位置以所用环境为准。

示例请求：

> 使用 reverse-anime-genga，把这张截图逆向成原画稿。保持原构图，合理判断分层，并补全画框外仅被截掉一小部分的结构。

定向修订：

> 保留这张稿的构图和色线，只修改标记：每个笔画写一次，字距、大小和倾斜更随意；标注压在线条上，不在周围擦白。

> 右侧手臂只缺肘部。扩大右侧纸面，把弯肘补完整，保持框内肩膀与手的位置不变。

### 不支持自动安装的环境

让 Agent 阅读 [SKILL.md](reverse-anime-genga/SKILL.md)，并能够继续读取其引用的资料文件，再提供截图和任务。若环境只有文本能力，可用于拟定逆向方案和检查标记逻辑，不能据此宣称已经生成图片。

## 参考与设计来源

本 skill 由多轮截图逆向实践、具体问题反馈和公开作画资料整理而成。参考资料包括 P.A.WORKS 的作画教学、REVOROOT 数字作画手册、日本アニメーション与 CELSYS 教程、WEBアニメスタイル摄影讲座、原画样例说明及动画人才培养资料。

完整链接和每份资料的用途见 [制作知识与来源](reverse-anime-genga/references/production-knowledge.md)。仓库保留归纳说明与出处，不打包第三方教程原文或样图。

不同公司和镜头会采用不同的素材划分、线色和流程。本 skill 将选定的白底呈现、单笔手写、选择性框外补画等作为默认输出约定，并不把这些偏好宣称为所有动画制作的统一标准。

## 能力边界

- 单张成片无法唯一确定真实原画、分层、时序、镜头运动或画外结构；输出是具有制作逻辑的逆向示意。
- 图像模型可能仍产生错误的手指、轮廓、日文或编号。需要检查生成结果，必要时定向修订。
- 图上标有 A/B 素材组，不代表输出图片已经包含真正可编辑的独立图层。
- 此版本已进行文本场景的方案检查；不把它当作对所有图像模型和镜头的效果保证。
